Outlook Gmail Sync

Outlook Gmail Sync is a personal, self-hosted application that automatically copies new emails from a Microsoft Outlook.com mailbox into a Gmail mailbox.

How it works

The application uses Microsoft Graph to read incoming Outlook emails and the Gmail API to import those messages into Gmail.

It runs on a privately managed server and uses OAuth 2.0 to authenticate both accounts.

Data handling

Email contents are transferred directly between the user's Microsoft and Google accounts through the self-hosted application. The application does not operate a public email-processing service.
